# スプレッドシート連携のセットアップ

所要5分ほど。ここで作る URL を、管理画面（`admin.html`）の「設定」タブに貼れば完了です。

## 1. スプレッドシートを作る

1. [Google スプレッドシート](https://sheets.google.com) で新しいファイルを作成
2. ファイル名を分かりやすく変更（例：`wellme 顧客管理`）

シートのタブは自分で作らなくて大丈夫です。初回アクセス時に `customers` / `reservations` / `waitlist` の3枚が自動で作られます。

## 2. スクリプトを貼り付ける

1. メニューの **拡張機能 → Apps Script** を開く
2. 最初から入っている `function myFunction() {}` を全部消す
3. このフォルダの **`Code.gs` の中身を全部コピーして貼り付け**
4. 保存（Ctrl+S）

## 3. ウェブアプリとしてデプロイする

1. 右上の **デプロイ → 新しいデプロイ**
2. 左の歯車から **種類を選択 → ウェブアプリ**
3. 設定を以下にする

   | 項目 | 値 |
   | --- | --- |
   | 説明 | 任意（例：v1） |
   | 次のユーザーとして実行 | **自分** |
   | アクセスできるユーザー | **全員** |

4. **デプロイ** を押す
5. 初回は権限の確認が出ます
   - 「アクセスを承認」→ 自分のアカウントを選択
   - 「このアプリは確認されていません」と出たら **詳細 → （プロジェクト名）に移動（安全ではないページ）** → **許可**
6. 表示された **ウェブアプリの URL をコピー**（`https://script.google.com/macros/s/....../exec`）

> **「アクセスできるユーザー」は必ず「全員」に**してください。「自分のみ」だとアプリから呼んだときにログイン画面のHTMLが返り、通信に失敗します。

## 4. 管理画面に URL を登録する

1. `admin.html` を開く（`node server.js` を起動して <http://localhost:5173/admin.html>）
2. 「設定」タブに URL を貼って **保存**
3. **接続テスト** を押して、スプレッドシート名が表示されれば成功

予約アプリ側は追加設定不要です。同じブラウザで URL を共有するので、予約が確定すると自動でシートに記録されます。

## スクリプトを更新したとき

`Code.gs` を編集したら、**デプロイ → デプロイを管理 → 鉛筆アイコン → バージョン「新バージョン」→ デプロイ** を実行してください。URL は変わりません。

（「新しいデプロイ」を選ぶと別のURLが発行されてしまうので注意）

## シートの中身

### customers（顧客マスタ）

| 列 | 内容 |
| --- | --- |
| customerId | 自動採番のID（`C` + 10桁） |
| name / kana / email / tel | 氏名・カナ・メール・電話 |
| memo | カルテメモ。管理画面から編集 |
| visitCount | キャンセル以外の予約件数。自動計算 |
| lastVisit | 最終来店日。自動計算 |
| createdAt / updatedAt | 登録日時・更新日時 |

### reservations（予約履歴）

予約が確定すると1行追加され、キャンセルすると `status` が `cancelled` になります。

### waitlist（キャンセル待ち）

満席日にキャンセル待ち登録が入ると記録されます。

## 注意点

- **顧客の名寄せ**はメールアドレス優先、無ければ電話番号で行います。どちらも一致しなければ新規顧客として登録されます。
- スプレッドシートは**行を手で編集しても大丈夫**ですが、`customerId` と `code` の列は変更しないでください（アプリ側の照合キーです）。
- URL を知っている人は誰でも読み書きできます。**顧客情報を入れる場合は URL を共有しないでください。** 本格運用するならログイン制限（Google アカウント限定デプロイ＋管理画面をGAS側でホスト）への変更を検討してください。
