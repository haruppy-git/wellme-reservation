# 美容院 予約アプリ（wellme）

`reserva.be/wellme` の予約フローと予約ルールを再現した、ビルド不要の静的Webアプリです。

## 起動

```bash
node server.js
```

`http://localhost:5173` を開きます。（`index.html` を直接開いても動きますが、ブラウザによっては localStorage が使えないためサーバー起動を推奨）

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 予約サイトの骨組み（ヘッダー・店舗情報・メイン領域・モーダル） |
| `style.css` | スタイル一式（予約サイト・管理画面で共用） |
| `data.js` | 店舗マスタ・メニュー・オプション・予約ルールの設定データ |
| `app.js` | 空き枠計算エンジン＋画面遷移（ハッシュルーティング） |
| `admin.html` / `admin.js` | 顧客管理画面（スタッフ用） |
| `sheet.js` | Google スプレッドシートとの通信クライアント（両方から使用） |
| `gas/Code.gs` | スプレッドシート側のバックエンド（Apps Script に貼る） |
| `gas/SETUP.md` | スプレッドシート連携のセットアップ手順 |
| `server.js` | 開発用の簡易静的サーバー |

## 再現した仕組み

### 予約フロー
```
メニュー一覧 → 日程選択 → 時間選択 → オプション選択
  → 会員ログイン / 連絡先を直接入力（ゲスト）
  → 連絡先入力 → 内容確認 → 予約確定（予約番号発行）
```

### 空き枠の判定
- 営業時間は曜日別（月09:00-19:00 ／ **火は定休日** ／ 水木金09:00-19:00 ／ 土日09:00-18:00）
- 予約枠は **30分刻み**、席数は **2席**（`SALON.capacity`）
- 施術時間が営業終了時刻に収まる開始時刻だけを枠として出す
  （例：60分メニューなら 19:00 閉店の日は 18:00 が最終枠）
- 枠ごとに施術時間ぶんの区間の同時予約数を数え、
  `○`（空きあり）／`△`（残1）／`×`（満席・受付終了）を表示

### 予約ルール（`data.js` の `RULES` で変更可）
| ルール | 値 | 挙動 |
| --- | --- | --- |
| 予約受付開始 | 3ヶ月前の00:00から | 3ヶ月先を超える月へはカレンダーを進められない |
| 予約受付締切 | 12時間前まで | 締切を過ぎた枠は `×`（受付終了）。確定直前にも再チェック |
| キャンセル締切 | 1日前の23:59まで | 期限を過ぎるとWebキャンセル不可の案内に切り替わる |

### そのほか
- **オプション**：選ぶと施術時間が延び、選択できる時間枠が再計算される。すでに選んだ時間が確保できなくなった場合は警告して選び直しを促す
- **キャンセル待ち**：満席日（`×`）をクリックするとメールアドレスで登録できる。キャンセル発生時に「◯名に通知」と表示
- **二重予約の防止**：確定ボタンを押した時点で締切と空きを再チェックする
- **予約の確認・キャンセル**：予約番号＋メールアドレスで照会
- **会員機能**：登録すると次回以降フォームが自動入力され、マイページで履歴確認・キャンセルができる

## データについて

- 予約・会員・キャンセル待ちは **ブラウザの localStorage** に保存されます（サーバーDBはありません）。
- 既存予約は日付から決まる擬似乱数で生成しているため、リロードしても空き状況は変わりません。1割ほどの確率で終日満席の日が現れます。
- **デモ用のため、実在するパスワードや個人情報は入力しないでください。** メール送信も行いません。

## カスタマイズ

営業時間・席数・メニュー・料金・オプション・予約ルールはすべて `data.js` にまとまっています。
`SALON.capacity` を 1 にすれば `○`/`×` のみの1席運用、`slotStep` を 15 にすれば15分刻みになります。

# 顧客管理アプリ（admin.html）

Google スプレッドシートをデータベースにしたスタッフ用の管理画面です。
<http://localhost:5173/admin.html>（予約サイトのフッターからも入れます）

## セットアップ

`gas/SETUP.md` の手順どおりにスプレッドシートへ `gas/Code.gs` を貼り、ウェブアプリとしてデプロイして、
出てきた URL を管理画面の「設定」タブに登録すれば完了です。API キーもサーバーも不要です。

## できること

| 画面 | 内容 |
| --- | --- |
| 顧客 | 一覧・検索（氏名/カナ/電話/メール）・並べ替え（最終来店/来店回数/氏名/登録日）・新規登録 |
| 顧客詳細 | 来店回数・最終来店日、基本情報、カルテメモの編集、来店/予約履歴、削除 |
| 予約 | 本日・今後・過去・すべての切り替え、検索、行クリックでその顧客へ |
| 設定 | 接続先 URL の登録・接続テスト、未送信データの再送 |

## 予約サイトとの連携

予約サイト側で以下が起きると、自動でスプレッドシートに記録されます。

| 操作 | 記録先 |
| --- | --- |
| 会員登録した | `customers` に1行追加（来店回数0）。予約がまだ無くても顧客一覧に出る |
| 予約が確定した | `reservations` に1行追加。顧客は**メール優先・無ければ電話番号**で名寄せし、初回なら `customers` に自動登録 |
| 予約をキャンセルした | 該当行の `status` が `cancelled` に。来店回数も計算し直される |
| キャンセル待ちを登録した | `waitlist` に1行追加 |

**通信に失敗しても予約は成立します。** 未送信ぶんはブラウザに溜まり、次回アクセス時か
管理画面の「今すぐ送信する」でまとめて送られます（設定タブに残件数が出ます）。

## デモデータの初期化

管理画面の「設定」タブ →「デモデータの初期化」から、確認欄に `RESET` と入力して実行します。

| | |
| --- | --- |
| 消えるもの | シートの `customers` / `reservations` / `waitlist` の全行、ブラウザの予約・会員・ログイン状態・未送信データ |
| 残るもの | 接続先URL、シートの見出し行、`data.js` のメニュー・営業時間などの設定 |

接続はつないだまま、すぐ次のデモを始められます。シートの行は完全に削除されるため取り消せません。

## 現状の制限

- 空き枠の判定は**ブラウザの localStorage を見ています**。スプレッドシートへの記録は予約サイト→シートの一方通行なので、
  別の端末で入った予約は空き枠に反映されません。共有カレンダーとして使うには、シートから予約を読み込んで
  `buildSlots()` に渡す改修が必要です。
- ウェブアプリ URL を知っていれば誰でも読み書きできます。実際の顧客情報を扱う場合は URL を共有せず、
  アクセス制限（Google アカウント限定デプロイなど）を検討してください。
